# Module D: fixed-configuration assessment of exposure correlation

## Objective and comparisons

Module D evaluates a fixed model configuration as the overall dependence among eight active exposures increases. The completed module B supplies the original-correlation reference. Two new exposure distributions represent moderate and high correlation. Response functions, effect coefficients, confounder process, matching calendar and model settings are shared. The new distributions are specified on the final exposure variables used in the response model.

| Setting | Target mean absolute Pearson correlation | Minimum absolute pairwise correlation | Mean tolerance | Source |
|---|---:|---:|---:|---|
| Original (D0) | Measured from B | Measured from B | — | Saved B fits and evaluation sample |
| Moderate (DM) | 0.60 | 0.45 | ±0.03 | New D data and fits |
| High (DH) | 0.85 | 0.75 | ±0.03 | New D data and fits |

The mean uses the 28 off-diagonal exposure pairs. Signed coefficients are retained in the matrices, while their absolute values define correlation strength. Original common-factor directions are retained in the recoupling. Each new setting has 100 independent repetitions. Every repetition fits KDR-CC under G1–G4 and each CLR comparator under two adjustment specifications. Correct-adjustment CLR results supply G1/G2 and incorrect-adjustment results supply G3/G4. This yields 1,600 new fits and 200 learned kernels. The default B reference contributes 800 existing fit records from 100 repetitions. Counts refer to model fits; each fit supplies multiple evaluation outputs.

## Data generation and calibration

Let A_j be a final, fixed-lag exposure generated by the original mechanism. An independent sample of 10,000 matched sets estimates each marginal distribution F_j. Sorted values and plotting positions (rank − 0.5)/n define fixed empirical forward and inverse maps. Gaussian scores are Z_j = Phi^{-1}{F_j(A_j)}.

For a given matched set, an independent common Gaussian process U has variance one and correlation phi^{|t−s|} between candidate dates t and s, using the specified autoregressive coefficient phi. Processes are independent across matched sets. With the signed direction s_j in the original mechanism, recouple the scores as

    Z_j* = sqrt(1 − eta) Z_j + sqrt(eta) s_j U,
    A_j* = F_j^{-1}{Phi(Z_j*)}.

Under continuous known marginal maps, each transformed score is standard normal and the marginal distribution is preserved. Fixed empirical maps implement this transformation approximately. Mean and standard-deviation checks are saved for every exposure. This transformation acts after the original concentration and lag operations; the transformed values are the fixed-lag exposure covariates in the outcome model.

A second independent sample of 10,000 matched sets calibrates eta by solving for the requested mean absolute Pearson correlation of A*. A third sample of 10,000 matched sets validates the mean tolerance and minimum pairwise correlation. An independent evaluation sample checks these requirements again. All maps and eta values are fixed before model fitting and reused across repetitions. Calibration uses exposure measurements only. Infeasible means or failed pairwise floors stop the run before model fits are dispatched.

Calendar matching and the generated confounder process are retained. Recoupling changes the joint exposure dependence, including temporal dependence and exposure–confounder associations. D therefore assesses the explicitly defined distributions rather than holding every feature of their joint law fixed. The conditional response remains h(A*) + g(W), with the specified coefficients; a new case date is sampled from the conditional event probabilities. The individual matched set remains intact through pair expansion, cross-fitting, estimation and covariance aggregation.

## Reusing the original-correlation reference

The submission locates B through D_baseline_run, the work-directory LATEST_B pointer, or a unique module_B_* directory. It requires the complete planned set of B fit records, including explicit failed records. It checks that N, L, M, kappa and lambda, and the mechanism, kernel, nuisance, solver, comparator, variable-test, interpretation and evaluation settings match D.

B's fits, learned kernels, evaluation sample and metadata are copied into the D run's baseline_B directory. Saved hashes and an import signature verify the copy. B's evaluation exposure sample is reconstructed from its recorded seed and checked against the saved actual-combination coordinates; this supplies the original overall correlation matrix. Existing B results remain in their original directory. The D report can be regenerated from a complete copied D run, including baseline_B.

## Common evaluation targets

The B evaluation file supplies the exact common reference concentrations, joint concentration path, single-exposure grids, OR contrasts and four-point interaction grids. These constructed coordinates and their true contrasts are identical across the three settings. Observed-combination effects, contribution shares and derivative-based exposure-identification summaries use each setting's own independent exposure distribution. Changes in these distribution-averaged quantities therefore include the effect of the altered exposure distribution.

B and D are independent simulation batches. Moderate and high D settings share underlying calendar, confounder and exposure random inputs within a repetition. Learning, final estimation and evaluation use separate streams. Settings have separate data, kernel and auxiliary caches.

## Evaluation and outputs

Cross-setting comparisons include RMS bias, RMSE, absolute OR relative error, standard-error calibration, interval coverage, significant-direction detection, contribution-share accuracy, interaction detection and exposure identification. Each correlation setting also receives the complete B-style G1–G4 assessment. Tables include usable counts and Monte Carlo uncertainty.

## Submission

The source directory and writable work directory are separate. With code_root=NULL and work_root=NULL, 05_submit.R locates its own source directory and uses the sibling KDRCC_formal_20261027 work directory. This layout is suitable for

    /XXX/KDRCC/simulated
    /XXX/KDRCC/KDRCC_formal_20261027

The existing work directory supplies config/fixed_parameters.R and the completed B run. D_overrides is empty by default, so D inherits the frozen model configuration. The plan verifies agreement with B. D_baseline_run=NULL selects B automatically; an explicit absolute path selects another completed B reference. D_correlation_levels specifies target_mean, min_abs and mean_tolerance. The requested PSOCK worker count is 32, with one BLAS/OpenMP thread per worker.

From the source directory, submit the check and review its log:

```bash
nohup Rscript --vanilla 05_submit.R check D > D_check.txt 2>&1 &
```

Then inspect the plan:

```bash
nohup Rscript --vanilla 05_submit.R plan D > D_plan.txt 2>&1 &
```

After confirming the B reference and model parameters, run D:

```bash
nohup Rscript --vanilla 05_submit.R run D > D_run.txt 2>&1 &
tail -f D_run.txt
```

After completion, report separately:

```bash
nohup Rscript --vanilla 05_submit.R report D > D_report.txt 2>&1 &
```

Progress messages show completed new fits, elapsed time and estimated remaining time. Saved fit records support resumption. Complete module result directories can be copied for local reporting through report_run_directories.
