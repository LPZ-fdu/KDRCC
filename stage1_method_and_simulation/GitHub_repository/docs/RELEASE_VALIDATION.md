# Source and result inventory

The review findings are in [FINAL_REVIEW.md](FINAL_REVIEW.md). The theory-to-code matrix, formal record counts and complete snapshot comparison are in `archive/`. `SOURCE_CHECKSUMS.csv` freezes the repository files. Runtime file inventories and Release-asset digests associate the source stage with the corresponding A–E records.

All five formal modules include their saved fit records, plans, configuration, source snapshots, sessions and publication analysis. Their original module directory names are preserved. [ARCHIVE_LAYOUT.md](ARCHIVE_LAYOUT.md) defines the Git/Release split, exclusions and restoration commands. Executable numerical and workflow checks remain in `tests/`; check-generated sample runs and temporary validation output are classified in the exclusion inventory.
