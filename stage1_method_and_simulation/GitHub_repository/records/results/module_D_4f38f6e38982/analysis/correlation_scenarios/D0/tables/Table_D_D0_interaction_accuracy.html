RMSE is sqrt(mean squared error over all usable repetitions and points). MCSE uses deletion of an entire repetition; the empirical SD is summarized on its root-mean-square scale. Identically zero anchor contrasts are excluded; other zero true effects enter the absolute-error summaries. Usable/planned counts are reported separately for each component. Independent repetitions determine Monte Carlo uncertainty. Fit scenario records the CLR adjustment fit and its original independent-repetition count. Interaction is defined by four function evaluations; additive CLR models have zero log-OR interaction by construction.
