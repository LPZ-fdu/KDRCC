# Worked examples

The example has X1 with a positive main effect, X2 with a protective main effect, an X1-by-X3 interaction, null X4 and a time-varying covariate W. It contains 800 sets of four dates. Data are generated by `kdrcc_example(800L, seed=702L)`.

```r
source("RUN_EXAMPLE.R", encoding="UTF-8")
```

The result is assigned to `example_analysis` with fields `fit`, `results` and `output`. Outputs are saved relative to the script directory.

| Output | Definition |
|---|---|
| `sample_assignment.csv` | Matched-set learning and estimation allocation |
| `joint_effect.csv` | Quantile-path joint contrasts, SEs and pointwise intervals |
| `single_effects.csv` | Fixed-background single-exposure curves |
| `observed_combination_predictions.csv` | OR predictions for twenty supplied combinations |
| `variable_participation.csv` | Derivative quadratic statistics, tail calculations and Holm decisions |
| `interaction_overall.csv` | Pair-wide interaction tests |
| `interaction_points.csv` | Four-point contrasts, pointwise tests and directions |
| `contribution_shares.csv` | Mean absolute and signed allocations and within-set shares |
| `specified_contrast.csv` | X1 Q75 versus Q25 contrast at the stated background |
| `fitted_model.rds` | Complete saved model |
| `analysis_objects.rds` | Result objects supporting independent reporting |
| `example_*.png` | Built-in graphics for the analysis |
| `session_info.txt` | Model summary and execution environment |

`RUN_TUNING.R` has its own three-part allocation and eight candidate configurations. It exposes `selection` and `fit_tuned` in R. `CUSTOM_PLOTS.R` reads example CSV files and saves custom PNG graphics; it requires ggplot2. The user guides document the complete sequence and the meanings of every returned field.
