# Bundled dependency

CompQuadForm 1.4.4 computes quadratic-form tail probabilities. Copyright and authorship are recorded in its DESCRIPTION file. Its license is GPL (>= 2).

`CompQuadForm_1.4.4.tar.gz` is the unchanged source archive included with the frozen simulation implementation. `CompQuadForm_1.4.4.zip` packages the installed Windows x64 binary from the R 4.4 library used for release validation; its Built field identifies R 4.4.3. The release installation test executes it with R 4.4.2. The source archive supplies the corresponding source for redistribution and compilation.

The kdrcc package itself consists of R code. Its source archive installs with R >= 3.6.3. The Windows kdrcc binary targets R 4.4. Compatible dependency repository binaries can be used on other platforms and R releases. Source dependency installation uses the platform's R compilation tools.
